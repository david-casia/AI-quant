# JoinQuant 全策略融合部署方案

## 一、系统架构

### 7模块融合交易系统

```
┌─────────────────────────────────────────────┐
│           AI综合评分引擎 (-10 ~ +10)          │
├──────┬──────┬──────┬──────┬──────┬────┬─────┤
│ RSI  │ MACD │ BOLL │ KDJ  │ 策略 │ ML │ MLS │
│ 1.0  │ 1.5  │ 1.0  │ 1.0  │ 1.5  │2.0 │ 1.5 │
├──────┴──────┴──────┴──────┴──────┴────┴─────┤
│        仓位管理 (0% / 15% / 40% / 70% / 80%) │
├─────────────────────────────────────────────┤
│     风控层 (ATR止损 + 固定止损7% + 回撤保护)   │
└─────────────────────────────────────────────┘
```

### 评分→仓位映射

| 评分 | 动作 | 目标仓位 |
|------|------|---------|
| ≥ +4.0 | 买入 | 70-80% |
| +1.5 ~ +4.0 | 偏多持有 | 40-55% |
| -1.5 ~ +1.5 | 观望 | 0-15% |
| -4.0 ~ -1.5 | 偏空减仓 | 0-10% |
| ≤ -4.0 | 卖出 | 0% |

## 二、部署步骤

### 步骤1：注册JoinQuant

1. 访问 https://www.joinquant.com
2. 手机号注册 → 完成实名认证
3. 新用户有免费试用期（通常7-30天）

### 步骤2：部署主策略

1. 登录后点击 **「策略」** → **「新建策略」**
2. 删除编辑器中的模板代码
3. 打开 `jq_full_strategy.py`，**全选复制粘贴**
4. 点击 **「编译」**（检查语法，Ctrl+S保存）
5. 设置回测参数：
   - 标的：`002594.SZ`
   - 起始资金：`100000`
   - 回测区间：`2025-07-07` ~ `2026-07-07`
   - 频率：`每天`
6. 点击 **「运行回测」** → 等待完成（约1-2分钟）

### 步骤3：查看回测结果

回测完成后查看：
- **策略概览**：总收益、年化收益、最大回撤、夏普比率
- **交易明细**：每笔买卖记录、盈亏统计
- **日志输出**：每日信号评分、动作、持仓状态
- **净值曲线**：与基准（沪深300）对比

### 步骤4：参数调优（研究模块）

1. 点击 **「研究」** → **「新建」** → **「Notebook (Python 3)」**
2. 打开 `jq_research_ml.py`，**全选复制粘贴**
3. 逐段运行（Shift+Enter）：
   - Cell 1-4：导入依赖、获取数据
   - Cell 5-6：ML模型训练对比（4种模型）
   - Cell 7-8：参数网格搜索（54组参数）
   - Cell 9-10：全策略融合回测 + 可视化
   - Cell 11：滚动风险分析

4. 记录最优参数，填回主策略的 `initialize()` 函数：
   ```python
   g.ma_short = 5          # ← 替换为最优MA短周期
   g.ma_long = 15          # ← 替换为最优MA长周期
   g.turtle_entry = 20     # ← 替换为最优海龟入场
   g.turtle_stop_mult = 2.0  # ← 替换为最优止损倍数
   ```

### 步骤5：模拟交易

1. 回测满意后，回到策略页面
2. 点击 **「模拟交易」** 按钮
3. 选择模拟模式：
   - **分钟级模拟**：更接近实盘（推荐）
   - **日线级模拟**：速度快
4. 设置初始资金（建议100000）
5. 点击 **「开始模拟」**
6. 系统每日自动运行策略，产生交易信号

### 步骤6：监控模拟交易

1. **「模拟交易」** 页面查看运行状态
2. 每日盘后查看日志：
   - 综合评分及各模块信号
   - 执行动作（买入/持有/卖出）
   - 持仓盈亏
3. 如需停止，点击 **「停止」** 按钮

## 四、策略核心逻辑

### 信号计算流程

```
每日开盘前(before_trading_start):
  1. 获取近250日K线数据
  2. 计算4大指标(RSI/MACD/BOLL/KDJ)信号
  3. 计算双均线+海龟策略持仓状态
  4. 滚动训练ML模型 → 预测涨跌概率
  5. MLS因子回归打分
  6. 加权综合评分 → 仓位决策
  7. 计算止损价(ATR止损 or 固定7%)

每日开盘(market_open, 9:35):
  8. 按目标仓位下单(order_target_value)

每日盘后(after_market_close):
  9. 记录持仓、盈亏、交易日志
```

### ML模型特性

- **算法**：纯NumPy逻辑回归（梯度下降，lr=0.05, epochs=800, L2=0.01）
- **特征**：8维（收益率1/3日、RSI偏离、MACD柱、布林位置、KDJ-J、量比、均线偏离）
- **标签**：下一日涨(1)/跌(0)
- **滚动窗口**：120天，每日重训练
- **输出**：涨概率(0~1) → 映射到评分-2~+2

### MLS因子特性

- **算法**：线性回归（正规方程）
- **因子**：11个（动量5/20日、反转3日、波动率、量比、RSI强度、MACD强度、布林带宽、KDJ动量、均线排列、ATR占比）
- **标签**：未来5日收益率
- **滚动窗口**：60天
- **输出**：预测收益 → 映射到评分-1.5~+1.5

## 五、风险控制

### 止损机制（三层）

| 层级 | 机制 | 触发条件 |
|------|------|---------|
| L1 | ATR移动止损 | 价格 < 海龟止损价（2×ATR） |
| L2 | 固定止损 | 价格 < 成本价×93%（-7%） |
| L3 | 评分止损 | 综合评分 ≤ -4.0 → 全部清仓 |

### 仓位限制

- 单只个股最大仓位：**80%**
- 观望区评分（-1.5~+1.5）：持仓不超过15%
- 止损触发：目标仓位强制设为0%

## 六、常见问题

### Q0: 回测收益为0%且完全没有交易？
A: 常见原因：
- ❌ **回调函数名/参数写错**：必须用 `handle_data(context, data)`，不能缺 `data` 参数
- ✅ 四个固定回调签名：`initialize(context)` / `before_trading_start(context)` / **`handle_data(context, data)`** / `after_market_close(context)`
- 检查`策略代码 → handle_data`函数是否被调用（看日志）


### Q1: 回测报错"attribute_history"未定义？
A: 确保代码在JoinQuant策略编辑器中运行，不要在本地Python环境运行。JoinQuant的API（`attribute_history`, `order_target_value`, `log`等）只在平台内可用。

### Q2: ML模型预测全是0.5（无区分度）？
A: 检查特征是否包含NaN，确保数据窗口≥120天。可在研究模块中用sklearn验证模型效果。

### Q3: 回测收益为负？
A: 正常现象。全策略融合系统在震荡市可能表现不佳，但在趋势行情中表现优异。检查：
- 回测区间是否有明显趋势
- 最大回撤是否在可接受范围（<15%）
- 夏普比率是否>0.5

### Q4: 模拟交易和回测结果差异大？
A: 原因：
- 滑点：模拟交易有真实滑点（设置了0.02元固定滑点）
- 成交量：实盘可能因涨停/跌停无法成交
- 数据延迟：模拟交易数据有15分钟延迟
建议：先模拟运行1-2周观察稳定性

### Q5: 如何调整参数？
A: 在研究模块运行 `jq_research_ml.py` 的参数网格搜索部分，找到Top 10参数组合，选择夏普比率最高且回撤可接受的参数填入主策略。
