📋 交易纪律原则（严格执行，知行合一）

▲ 买入纪律

  • 综合评分 ≥ +4 且看涨信号 ≥ 3个，方可买入
  • 15:00前提交买入 → 当日收盘价确认；15:00后 → 次交易日确认
  • 分批建仓：首仓50%，确认后加至80%，满仓不超80%
  • 只在金叉/突破上轨时入场，不追涨、不抄底
  • 买入当日不可卖出（T+1），需设好止损位

✕ 卖出纪律

  • 综合评分 ≤ -4 或死叉形成，立即卖出
  • 15:00前提交卖出 → 当日收盘价确认成交
  • 跌破止损位 无条件平仓，不抱侥幸，不等反弹
  • 超买信号叠加(J>100且RSI>70)，分批获利了结
  • 卖出资金T+1日到账可用，盈利绝不止损变加仓

⚡ 风险管理

  • 单只个股仓位 不超总资金70%，留有现金储备
  • 止损幅度控制在 5%-8%，单笔亏损不超总资金2%
  • 评分在 -1.5 ~ +1.5 之间为观望区，空仓等待
  • 信号矛盾时(看涨看跌各半)，优先保住本金，不操作
