## 三、参数调优流程

### 方法1：手动调参（在策略编辑器中）

修改 `initialize` 函数中的参数：

```python
# 双均线参数
g.ma_short = 5    # 调整：3, 5, 10
g.ma_long = 20    # 调整：10, 15, 20, 30, 60

# 海龟参数
g.dc_entry = 20   # 调整：10, 15, 20, 25, 55
g.dc_exit = 10    # 调整：5, 7, 10, 15
g.atr_period = 20  # 调整：14, 20
g.stop_atr_mult = 2.0  # 调整：1.0, 1.5, 2.0, 3.0
```

每次修改后重新编译运行，记录结果。

## 五、风险分析方法

### 在研究模块运行风险分析

```python
# 复制 jq_param_optimization.py 中的 rolling_risk_analysis() 函数
# 运行后获取：
# - 日VaR(95%): 单日最大亏损95%置信度
# - 日CVaR(95%): 极端情况下的平均亏损
# - 滚动夏普比率: 60日窗口的风险调整收益
# - 滚动最大回撤: 60日窗口的最差表现
```

### 风险评估指标解读

| 指标 | 含义 | 安全阈值 |
|------|------|---------|
| VaR(95%) | 95%概率下单日亏损不超过此值 | <-3%需警惕 |
| CVaR(95%) | 极端5%情况下的平均日亏损 | <-5%需减仓 |
| 最大回撤 | 历史最大峰谷跌幅 | <-20%需停策略 |
| 夏普比率 | 每单位风险的超额收益 | >1.0为良好 |
| Calmar比率 | 年化收益/最大回撤 | >1.0为良好 |

## 六、经验与教训

### 经验总结

1. **信号确认优先**：双信号（金叉+突破）比单一信号更可靠
2. **止损纪律**：ATR移动止损能有效控制下行风险
3. **参数敏感性**：短周期参数（MA5/20）信号频繁但灵活；长周期（MA20/60）信号稀少但稳定
4. **趋势跟踪特性**：海龟策略在单边趋势市场表现优异，震荡市容易假突破

### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 回测收益高，实盘亏损 | 滑点+未来函数 | 开启use_real_price，增加滑点0.2% |
| 信号过于频繁 | 参数太短 | 增大均线/通道周期 |
| 最大回撤过大 | 无止损或止损太宽 | 增加ATR止损，止损倍数2.0 |
| 成交量不足 | 流动性问题 | 设置order_volume_ratio=0.25 |

### 教训

1. **避免过拟合**：不要为了追求高夏普而过度调参，参数在合理范围内即可
2. **交易成本不可忽略**：佣金+印花税+滑点累计约0.5%每笔，频繁交易会侵蚀利润
3. **单一标的风险集中**：比亚迪单只股票波动较大，实际应用应分散到多只标的
4. **模拟 ≠ 实盘**：模拟交易的环境与真实市场有差异，心理因素也会影响执行
